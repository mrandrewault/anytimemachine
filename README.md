# Anytime Machine

A static site. No build step, no dependencies, no framework.
Every page is one self-contained HTML file.

    index.html            the front door
    rings/index.html      the zoomable tunnel
    timeline/index.html   the scrolling timeline
    stars/index.html      the connection field
    vercel.json           static settings

To change the site, replace a file and push. That is the whole workflow.
